## Setup
1. Download or clone this repository.
2. Open the folder in VS Code and install the **Live Server** extension
   (or put the folder in XAMPP `htdocs` and start Apache).
3. Right-click `books.html` and choose **Open with Live Server**
   (or go to `http://localhost/lab4b/books.html` with XAMPP).
   Do not open it with file://, because `fetch()` will not work.
4. Open `jquery-dom.html` the same way. It needs internet for the jQuery CDN.
